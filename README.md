# นิยมตรวจหวยไทย

ชุดหน้าเว็บสาธารณะสำหรับตรวจผลสลากกินแบ่งรัฐบาล ชื่อ **นิยมตรวจหวยไทย**

## สิ่งที่พร้อมแล้ว

- หน้าเว็บภาษาไทยแบบมือถือมาก่อน พร้อมแบบฟอร์มตรวจเลข 6 หลัก
- UI รับ API สองรายการ: `GET /api/latest` และ `GET /api/check?number=123456`
- หลีกเลี่ยงการฝังผลรางวัลตัวอย่างหรือผลที่ไม่ได้ยืนยัน เพื่อไม่ทำให้ผู้ใช้เข้าใจผิด
- มีลิงก์ตรวจสอบซ้ำกับ GLO และข้อความแจ้งว่าเว็บไซต์ไม่ใช่ช่องทางรับเงินรางวัล

## การเชื่อมข้อมูลก่อนเปิดใช้งานจริง

ให้สร้าง backend ที่เรียก **GLO Open Data API** ฝั่งเซิร์ฟเวอร์เท่านั้น แล้วแปลงผลลัพธ์เป็นรูปแบบนี้:

```json
{
  "drawDate": "2026-10-16",
  "drawDateThai": "งวดวันที่ 16 ตุลาคม 2569",
  "fetchedAt": "2026-10-16T10:00:00+07:00",
  "prizes": {
    "first": { "numbers": ["123456"], "amount": 6000000 },
    "front3": { "numbers": ["123", "456"], "amount": 4000 },
    "back3": { "numbers": ["789", "012"], "amount": 4000 },
    "last2": { "numbers": ["34"], "amount": 2000 }
  }
}
```

อย่าเรียก GLO จาก browser โดยตรง: เก็บ URL/คีย์ไว้ในตัวแปรลับของ server, ตรวจ schema ของผลลัพธ์ก่อนบันทึก, และเผยแพร่เฉพาะผลที่ผ่านการยืนยันแล้ว. ตั้ง scheduled job ให้ตรวจทุก 15 นาทีในวันออกรางวัล และให้ตรวจวันถัดไปด้วยหากมีการเลื่อนออกรางวัล.

## ความปลอดภัยสำหรับระบบจริง

- ให้ระบบสาธารณะอ่านผลได้อย่างเดียว; แยก `/admin` ออกจากเว็บสาธารณะ
- ปกป้อง `/admin` ด้วย identity provider ที่อนุญาตเฉพาะอีเมลเจ้าของ 1 บัญชี และบังคับ MFA/passkey
- ไม่เปิดหน้าสมัครสมาชิก, จำกัดอัตราคำขอ API, เปิด WAF/HTTPS, สำรองฐานข้อมูลและเก็บ audit log
- เก็บความลับใน secret manager ห้ามใส่ API key ใน `app.js` หรือ Git

## ข้อกำหนดข้อมูล

GLO ระบุชุดข้อมูลผลรางวัลเป็นข้อมูลเปิดภายใต้ **Creative Commons Non-Commercial (Any)**. ก่อนนำเว็บไปหารายได้ โฆษณา หรือขายบริการ ต้องขออนุญาตหรือยืนยันสิทธิการใช้งานกับ GLO ก่อน.
